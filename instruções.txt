Você está atuando como engenheiro de software sênior no repositório ZeroInsight.

Contexto:
O ZeroInsight é um software Python para geração de posts e Stories de Instagram com IA, usando comunicação visual da empresa, documentos PDF/DOCX, BrandProfile, providers de IA, geração de imagem, renderização final e validação de marca/compliance.

O projeto já possui CLI, UI desktop, pipeline de Stories, pipeline de posts, Brave/CDP e estrutura modular. Agora quero evoluir o software para um produto mais profissional.

Objetivo desta tarefa:
Implementar suporte robusto à OpenAI Platform para geração de texto e imagem, melhorar profundamente a interface do usuário e melhorar o prompt de geração de imagem.

Diretriz arquitetural principal:

* O backend deve continuar sendo Python.
* O frontend pode ser feito com qualquer tecnologia moderna, desde que fique melhor, mais limpo, mais usável e bem documentado.
* Se a UI atual em PySide6 estiver limitando o produto, você pode migrar para uma arquitetura com frontend web moderno e backend Python.
* Sugestão preferida: React + Vite + TypeScript + Tailwind + shadcn/ui no frontend, FastAPI no backend Python, e empacotamento desktop futuro via Tauri ou similar.
* Não faça uma reescrita burra e destrutiva. Preserve as pipelines existentes e exponha-as por serviços/APIs.

Parte 2 — OpenAITextProvider

Implementar provider oficial OpenAI para texto.

Criar ou ajustar:

zero_insight/ai_providers/text/openai_text_provider.py

Requisitos:

1. Usar OpenAI Python SDK se já estiver no projeto; caso contrário adicionar dependência oficial openai.
2. Usar Responses API para geração textual.
3. Configurar por ambiente/settings:
   OPENAI_API_KEY
   OPENAI_TEXT_MODEL
   OPENAI_REASONING_MODEL
   OPENAI_BASE_URL opcional
4. Nunca logar API key.
5. Mascarar API key na UI.
6. Implementar:

   * generate_text()
   * generate_json()
   * generate_structured()
   * extract_brand_profile()
   * generate_story_script()
   * generate_post_copy()
   * generate_image_prompt()
   * validate_compliance()
7. Para respostas estruturadas, usar JSON Schema/Structured Outputs quando possível.
8. Se Structured Outputs falhar, aplicar fallback:

   * tentar parse JSON;
   * tentar correção uma vez;
   * se falhar, retornar erro amigável.
9. Registrar uso no manifest:
   ai_text_provider: openai
   ai_text_model
   task_type
   created_at

Modelos:

* default para texto/copy: gpt-5.4-mini ou modelo configurável.
* default para análise pesada/compliance: gpt-5.5 ou modelo configurável.
* não hardcodar de forma rígida; permitir alterar na UI/config.

Parte 3 — OpenAIImageProvider

Implementar provider oficial OpenAI para imagem.

Criar ou ajustar:

zero_insight/ai_providers/image/openai_image_provider.py

Requisitos:

1. Usar OpenAI Images API para geração direta de imagem.
2. Modelo padrão:
   OPENAI_IMAGE_MODEL=gpt-image-2
3. Permitir fallback configurável:

   * gpt-image-1.5
   * gpt-image-1
   * gpt-image-1-mini
4. Configurar:
   OPENAI_IMAGE_SIZE
   OPENAI_IMAGE_QUALITY
   OPENAI_IMAGE_FORMAT
   OPENAI_IMAGE_BACKGROUND
5. Para Stories, gerar imagem base vertical.
6. Se o modelo não aceitar exatamente 1080x1920, gerar no tamanho vertical suportado mais próximo e deixar o renderer redimensionar/exportar para 1080x1920.
7. A imagem gerada pela IA deve ser apenas base/fundo/ilustração.
8. Proibir texto dentro da imagem gerada.
9. Proibir logotipo fictício.
10. Proibir marca falsa.
11. O texto, logo, CTA e elementos finais devem continuar sendo aplicados pelo renderer do ZeroInsight.
12. Salvar imagem no output_path.
13. Suportar resposta base64.
14. Registrar revised_prompt se a API retornar.
15. Registrar no manifest:
    ai_image_provider: openai
    ai_image_model
    ai_image_size
    ai_image_quality
    revised_prompt
    cost_estimate se já houver base para estimar, senão null.

Parte 5 — Melhorar o prompt de geração de imagem

Criar um prompt builder profissional para imagem.

Arquivo sugerido:

zero_insight/image/prompt_builder.py
ou
zero_insight/brand/brand_prompt_builder.py

O prompt final deve ser construído a partir de:

* BrandProfile
* tema
* objetivo
* público
* formato
* StorySlide
* visual_idea
* paleta de cores
* estilo visual
* regras de layout
* regras proibidas
* safe zone
* destino: Instagram Story ou feed post

Criar template base:

SYSTEM / INSTRUCTION:
You are an expert art director and brand designer creating background visuals for institutional social media content.

Your task is to generate a clean base image for a social media layout. The final text, logo, CTA, and UI elements will be added later by the application.

Do not generate any text inside the image.

USER PROMPT TEMPLATE:
Create a vertical institutional background image for an Instagram Story.

Format:

* Vertical 9:16 composition.
* Intended final export: 1080x1920.
* Leave safe empty space for text overlays.
* Keep the top and bottom areas visually clean because Instagram UI may cover them.
* Main subject must not block the center text area.
* No text.
* No letters.
* No captions.
* No fake logos.
* No watermarks.
* No UI mockups unless explicitly requested.
* No exaggerated marketing clichés.
* No unrealistic legal or financial promises.

Brand:
{brand_name}

Brand tone:
{tone_of_voice}

Visual style:
{visual_style}

Preferred colors:
{color_palette}

Typography notes, for renderer only:
{typography_notes}

Layout rules:
{layout_rules}

Topic:
{topic}

Objective:
{objective}

Audience:
{audience}

Visual idea:
{visual_idea}

Desired mood:
Trustworthy, modern, clean, institutional, professional, calm, credible.

Composition:

* Clean background.
* Strong visual hierarchy.
* High contrast.
* Room for headline and CTA overlay.
* Subtle depth.
* Minimal clutter.
* Realistic or semi-realistic style depending on BrandProfile.
* Avoid busy details behind expected text zones.

Negative instructions:

* Do not include text.
* Do not include numbers.
* Do not include charts with unreadable labels.
* Do not include fake legal documents with visible text.
* Do not include fake brand marks.
* Do not include distorted hands, faces, documents, seals, gavels, money, or flags unless specifically requested.
* Do not imply guaranteed financial/legal result.
* Do not create sensationalist imagery.

Output:
One clean background image suitable for final layout composition.

Também criar versões:

1. story_background_prompt
2. feed_post_background_prompt
3. carousel_slide_background_prompt
4. metric_visual_prompt
5. brand_asset_prompt

O sistema deve armazenar o prompt usado no manifest.
